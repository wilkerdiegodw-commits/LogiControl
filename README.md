
# LogiControl

Sistema de gerenciamento logístico desenvolvido como atividade prática da disciplina Fundamentos de Programação para Internet da UNIPAR.

## Tecnologias utilizadas
- PHP
- HTML e CSS
- Bootstrap
- MySQL
- XAMPP

## Funcionalidades
- Cadastro e edição de produtos
- Cadastro e edição de endereços
- Cadastro e edição de transportadores
- Geração de fretes
- Consulta e edição de fretes
- Download de relatórios de fretes por data

## Banco de dados
Nome do banco: logicontrol

## Como executar
1. Instale o XAMPP.
2. Coloque a pasta logicontrol dentro de htdocs.
3. Inicie Apache e MySQL.
4. Crie o banco logicontrol e importe a estrutura SQL do projeto.
5. Configure a conexão local no arquivo conexao.php.
6. Acesse http://localhost/logicontrol/

## Objetivo
Facilitar o gerenciamento de informações logísticas, permitindo organizar produtos, endereços, transportadores e fretes.
